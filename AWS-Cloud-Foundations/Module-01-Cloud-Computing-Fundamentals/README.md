# Module 01 - Cloud Concepts Overview

This module introduces the foundational concepts of cloud computing, cloud adoption benefits, AWS fundamentals, and the AWS Cloud Adoption Framework (CAF).

It serves as the foundation for the remaining AWS Academy Cloud Foundations course modules.

## Topics Covered

### Cloud Computing

* Cloud Computing Fundamentals
* Traditional IT vs Cloud Computing
* Infrastructure as Software
* Resource Concepts
* Scalability and Elasticity
* Service Models (IaaS, PaaS, SaaS)
* Deployment Models
* AWS vs Traditional IT

### Advantages of Cloud Computing

* Trade CapEx for Variable Expense
* Benefit from Massive Economies of Scale
* Stop Guessing Capacity
* Increase Speed and Agility
* Stop Spending Money Running and Maintaining Data Centers
* Go Global in Minutes

* Operations Perspective

## Learning Objectives

* Understand the core concepts of cloud computing
* Identify the business value of cloud adoption
* Understand AWS global infrastructure and service categories
* Learn how AWS services are accessed and managed
* Understand the AWS Cloud Adoption Framework (CAF)
* Build a foundation for future AWS services and architecture topics
